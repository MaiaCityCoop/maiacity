# Intent 99b612ec: scratch work for people who move like people

This is the builder's scratch work for intent 99b612ec-afa2-4dad-820b-cd2e0aff6bf5, kept on its branch. It is not
part of play or the site:

- `mocap.mjs` reads BVH and glTF captures.
- `retarget.mjs` retargets them onto the VRM humanoid skeleton.
- `pieces/` holds the readable pieces as they are proposed to play.
- `mcp.mjs` calls play's MCP tools from a script.
